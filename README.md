# Circle Run — лабораторная работа №9

2D-арена на **Unity 6000.6.8f1 (237b6593792b)**. Голубой квадрат убегает от красных кругов; цель — продержаться как можно дольше.

## Запуск

1. Открой папку проекта через Unity Hub редактором **6000.6.8f1**.
2. Дождись импорта и открой `Assets/Scenes/MainScene.unity`.
3. Нажми **Play**, щёлкни в окне **Game** и нажми **Enter** или кнопку начала раунда. Для клавиш используй английскую раскладку.

Для удобного отображения интерфейса выбери соотношение сторон Game **16:9**. Арена целиком помещается в камеру и при других пропорциях.

## Управление

| Клавиша | Действие |
| --- | --- |
| Enter | Начать игру |
| WASD / стрелки | Движение |
| Shift | Бег, скорость ×2 |
| Пробел | Рывок в последнем направлении движения |
| Q / E | Вращение квадрата |
| R | Начать новый раунд |

Рывок длится **0,18 с**, даёт неуязвимость на это время и восстанавливается **2,5 с**. Полоса внизу показывает готовность. Стены ограничивают арену даже во время рывка.

## Правила

- Таймер считает время текущего раунда. Касание противника завершает игру.
- Лучший результат хранится между запусками в `PlayerPrefs` (`CircleRun.BestSeconds.v1`).
- Каждые **10 с** появляется новый преследователь. Скорость всех врагов растёт на **0,12 ед./с** за волну, максимум — **4,2 ед./с**.
- **Зелёный щит** поглощает один удар, отталкивает ближайших врагов и даёт секунду для отхода. Несколько щитов не складываются.
- **Фиолетовый бонус** замедляет врагов до **45 %** скорости на **6 с**.
- **Жёлтый бонус** повышает скорость игрока в **1,45 раза** на **6 с**; эффект сочетается с бегом.
- Повторный бонус обновляет длительность. В начале доступны все три вида; затем случайный бонус появляется каждые **7 с**, если на арене меньше трёх. Неподобранные бонусы исчезают через **14 с**.
- Перезапуск возвращает исходные позиции, одного врага, три бонуса и обнуляет активные эффекты.

## Структура

- `PlayerController` — ввод, физическое движение, вращение, рывок и защита.
- `EnemyFollow` — преследование игрока.
- `CollisionReporter` — обработка контакта с врагом, включая длительное касание.
- `SurvivalGame` — раунды, таймер, рекорд, появление врагов и бонусов, стены и сетка арены.
- `BonusPickup` — подбор и срок жизни бонуса.
- `SurvivalHud` — интерфейс без дополнительных UI-пакетов.
- `Pulse.anim` / `PlayerAnimator.controller` — зацикленная анимация масштаба из лабораторной.

Стены, сетка, бонусы и HUD создаются при запуске сцены. Их параметры доступны у **GameManager → Survival Game**. Ввод читается в `Update`, движение — в `FixedUpdate`; используется `Rigidbody2D.linearVelocity`. Настройка **Active Input Handling = Both** сохранена.

## Проверка

В редакторе открой **Tools → Circle Run → Run gameplay checks** вне Play Mode. Проверки запускают сцену, подбирают бонусы через физические триггеры, проверяют рывок и стену, ждут появления второго врага, завершают раунд реальным столкновением и проверяют перезапуск. Результат — в Console и `Logs/ArenaChecks.txt`. Проверки восстанавливают прежний личный рекорд.

Для клонирования достаточно файлов `Assets`, `Packages`, `ProjectSettings` и этого README. Кэш Unity, отчёт и его генератор для запуска не нужны.
