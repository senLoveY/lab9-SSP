# Лабораторная работа 9 — Unity

Лабораторная работа №9: разработка интерактивного 2D-приложения в Unity.
Задания взяты из `Lab10_Unity.docx`; в отчёте и проекте используется номер 9.
Версия редактора: **6000.6.8f1 (237b6593792b)**.

## Запуск

1. Склонируй репозиторий: `git clone git@github.com:senLoveY/lab9-SSP.git`.
2. В Unity Hub выбери **Projects → Add → Add project from disk** и укажи папку `lab9-SSP`, где находятся `Assets`, `Packages` и `ProjectSettings`.
3. Открой проект редактором **6000.6.8f1**. Дождись импорта ресурсов и компиляции.
4. В окне Project открой `Assets/Scenes/MainScene.unity` двойным щелчком.
5. Нажми **Play**, затем щёлкни внутри окна **Game**, чтобы оно получало ввод с клавиатуры. При необходимости переключи раскладку на английскую.

Готовый отчёт: [lab9.docx](lab9.docx). Исходные скриншоты находятся в
`report/screenshots`. Кэш Unity и промежуточные файлы оформления исключены
через `.gitignore`.

На тёмном фоне находятся голубой квадрат Player и красный круг Enemy.
Квадрат непрерывно меняет масштаб от 1 до 1.5 и обратно за одну секунду.
Круг движется к игроку. При контакте игрок окрашивается в красный цвет,
после расхождения возвращается исходный цвет.

| Клавиши | Действие |
| --- | --- |
| WASD / стрелки | Движение по осям сцены |
| Левый или правый Shift | Ускорение в 2 раза при удержании |
| Q / E | Вращение против / по часовой стрелке |

Движение не поворачивается вместе с квадратом: WASD всегда задают направления
по мировым осям. Границ уровня нет, поэтому игрок может выйти за пределы камеры.
Останови Play и запусти его снова, чтобы вернуть исходные позиции.

## Что реализовано

- Базовое задание: 2D-сцена, управление и вращение Player, зацикленная анимация `Pulse` через `Animator`.
- Задание 1: скорость 5 единиц/с, с Shift — 10 единиц/с. Вектор ввода нормализуется, поэтому по диагонали скорость та же.
- Задание 2: Enemy преследует Player со скоростью 2 единицы/с. `Vector2.MoveTowards` вычисляет следующий шаг, из которого получается скорость тела.
- Задание 3: оба объекта имеют динамический `Rigidbody2D` без гравитации. На игроке — `BoxCollider2D`, на противнике — `CircleCollider2D`; триггеры выключены.
- Дополнительно: изменение цвета игрока при столкновении (`CollisionReporter`).

Ввод читается в `Update`, а физическое движение и вращение выполняются в
`FixedUpdate`. В Unity 6 свойство скорости называется `Rigidbody2D.linearVelocity`:
это используемый здесь эквивалент `rb.velocity` из методички.
В настройках проекта уже установлен `Active Input Handling = Both`.

Основные файлы: `Assets/Scripts/PlayerController.cs`, `EnemyFollow.cs`,
`CollisionReporter.cs`, `Assets/Animations/Pulse.anim` и
`Assets/Animations/PlayerAnimator.controller`.

1. В Console нет красных ошибок после открытия проекта и запуска Play.

## Контрольные вопросы

**1. В чём отличие Start и Update?**
`Start` вызывается один раз перед первым обновлением включённого компонента.
`Update` вызывается каждый кадр, пока компонент и объект активны.
Здесь получение Rigidbody выполнено в `Awake`, который подходит для начальной
настройки компонента до `Start`.

**2. Для чего используется Time.deltaTime?**
Это время между кадрами. Умножение скорости на это время превращает её в
перемещение за кадр и делает движение независимым от FPS. В физическом цикле
используется `Time.fixedDeltaTime`. В `linearVelocity` записывается скорость
в единицах в секунду, поэтому дополнительно умножать её на время не нужно.

**3. Какие клавиши обрабатывает Input.GetAxis("Horizontal")?**
При стандартных настройках Input Manager — A/D и стрелки влево/вправо.
Для `Vertical` — W/S и стрелки вверх/вниз. Здесь используется `GetAxisRaw`,
чтобы ввод реагировал без сглаживания.

**4. Что такое компонент и как он связан с GameObject?**
GameObject — объект сцены, а компоненты определяют его данные и поведение.
Например, `Transform` хранит положение, `SpriteRenderer` рисует спрайт,
`Rigidbody2D` участвует в физике, скрипт управляет объектом.

**5. Как создать анимацию без написания кода?**
Выбрать объект, открыть окно Animation, создать клип, включить запись и
расставить ключи изменяемого свойства на временной шкале. Для пульсации:
Scale X/Y = 1 на 0 с, 1.5 на 0.5 с и 1 на 1 с. Включить Loop Time;
Animator проигрывает клип через контроллер.

**6. Зачем нужна настройка Active Input Handling = Both?**
Она разрешает старый Input Manager и новую Input System одновременно.
Скрипты методички используют старый `UnityEngine.Input`, поэтому режим
только новой системы им не подходит. Для этих скриптов достаточно и старого
Input Manager, но в проекте сохранён режим Both из методички.
