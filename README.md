# Лабораторная работа 9 — Unity

Интерактивное 2D-приложение: управление игроком, ускорение, вращение,
пульсация, преследование и физические столкновения.

## Требования

Unity Editor **6000.6.8f1 (237b6593792b)**. Версия зафиксирована в
`ProjectSettings/ProjectVersion.txt`.

## Запуск

1. Склонируйте репозиторий:
   ```sh
   git clone git@github.com:senLoveY/lab9-SSP.git
   ```
2. В Unity Hub выберите **Projects → Add → Add project from disk** и укажите папку `lab9-SSP`.
3. Откройте проект в Unity **6000.6.8f1** и дождитесь импорта ресурсов.
4. Откройте `Assets/Scenes/MainScene.unity` и нажмите **Play**.
5. Щёлкните в окне **Game**, чтобы оно получало ввод с клавиатуры.

| Клавиши | Действие |
| --- | --- |
| WASD / стрелки | Движение |
| Левый или правый Shift | Ускорение вдвое |
| Q / E | Вращение |

Игрок пульсирует, противник автоматически приближается к нему.
При контакте игрок меняет цвет. Границы уровня не предусмотрены:
для восстановления начальных позиций остановите Play и запустите его снова.

## Состав проекта

- `Assets` — сцена, скрипты, спрайты и анимация вместе с файлами `.meta`.
- `Packages` — зависимости Unity.
- `ProjectSettings` — настройки проекта, ввода и физики.

Unity создаст кэш `Library` и временные файлы при первом открытии.
Режим **Active Input Handling = Both** уже включён в настройках проекта.
