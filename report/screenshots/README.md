# Скриншоты для отчёта

Нужны реальные снимки проекта в Unity 6000.6.8f1. Поддерживаются PNG и JPEG.

1. `scene.png` — открытая MainScene: видны Player, Enemy, Hierarchy и Inspector выбранного Player. Снимок вставляется в подраздел 3.1.
2. `collision.png` — вкладка Game в режиме Play, игрок касается противника и окрашен в красный. Снимок вставляется в подраздел 3.5.
3. `animation.png` — выбран Player, открыто окно Animation с клипом Pulse и ключами масштаба на 0, 0.5 и 1 секунде. Снимок вставляется в подраздел 3.6.

После добавления изображений выполнить из корня проекта:

```sh
python3 report/make_report.py
```

Генератор добавляет изображения вместе с вводным текстом, подписями и пояснениями,
пересчитывает номера последующих рисунков и ссылки на них. Если снимка нет,
он не вставляет пустое место или фиктивное изображение. Наличие скриншота само
по себе не подтверждает все сценарии ручной проверки из подраздела 3.7.

Для пересборки используются включённый в репозиторий `lab9.docx`, Python 3,
пакеты `python-docx` и `Pillow`, а также шрифты Arial и Times New Roman в macOS.
